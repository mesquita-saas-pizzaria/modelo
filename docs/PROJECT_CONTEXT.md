# VISÃO DO PROJETO

O Mesquita Commerce é um modelo profissional de site para pequenos comércios.

A primeira versão será voltada para pizzarias.

Posteriormente serão criados modelos para:

- Hamburguerias
- Restaurantes
- Lanchonetes
- Açaí
- Sorveterias
- Cafeterias
- Padarias
- Pet Shops
- Clínicas
- Academias
- Salões
- Barbearias
- Mercados
- Lojas em geral

A ideia é possuir apenas UM código-base.

Todo o conteúdo do site será carregado através do arquivo JSON.

Assim basta trocar o JSON para criar um novo site.
